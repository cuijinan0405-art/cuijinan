# 一句话配音（IndexTTS2）

## When to Use
- 用户输入 `/voice <文字>`，或者说「帮我配个音」「把这段读出来」「用xx的声音念…」「做段口播」。
- 优先使用本地工具 `mcp_media_text_to_speech`，不要用 Hermes 自带的在线 TTS。

## 怎么做
1. 分清楚「要念的内容」和「要求」：
   - `/voice 用温柔女声，开心地说：今天天气真好` → text = "今天天气真好"，voice = "温柔女声"，emotion = "开心"
   - 用户只给了一段话 → 整段都是 text，不要改写用户的原文。
   - 用户让你「写一段…并配音」→ 先写好文案，再把文案作为 text。
2. 音色 `voice`：用预设音色名，支持模糊匹配（「女」→「温柔女声」）。不确定有哪些时先调 `mcp_media_list_voices`。
   没说就按内容挑：旁白/纪录片 → 旁白·沉稳男声；情感/种草 → 温柔女声；资讯 → 新闻播报；带货 → 活力带货。
   列表里没有的就留空用默认音色。
3. 情绪 `emotion`：优先用预设名——跟随音色、平静舒缓、开心、激动热情、温柔、悲伤、生气、惊讶、害怕、低沉神秘、撒娇可爱、严肃播报；
   预设都不贴切时可以写一句简短的情绪描述。没提情绪就留空（用音色自带的默认情绪）。
4. 文本很长（超过 500 字）时按段落拆成几次调用，分别返回。
5. 把返回结果里的 `MEDIA:/路径` **原样**放进回复，再用一句话说明用的音色和情绪。

## 示例
- `/voice 欢迎收看本期节目` → text = "欢迎收看本期节目"
- `/voice 用旁白的声音，低沉地说：故事，要从三十年前说起` → text = "故事，要从三十年前说起"，voice = "旁白"，emotion = "低沉神秘"
