# 一句话出图（千问 Qwen-Image 2.1）

## When to Use
- 用户输入 `/img <描述>`，或者说「画一张…」「出个图…」「来张…的图」「做个封面/海报」。
- 优先使用本地工具 `mcp_media_generate_image`，不要用其他在线出图工具。

## 怎么做
1. 把用户的话扩写成一段具体的提示词（中文即可）：主体 + 场景 + 风格 + 光线 + 构图 + 画质词。
   - 用户要求图中出现的文字，原样用引号写进提示词（千问 Image 擅长渲染中文文字）。
   - 用户只说了很短一句也不用追问，直接按合理默认扩写后出图。
2. 判断画幅 `ratio`：
   - 手机壁纸 / 竖版海报 / 小红书 / 抖音封面 → `9:16` 或 `3:4`
   - 电脑壁纸 / 横版封面 / B 站封面 / PPT 配图 → `16:9`
   - 头像 / 表情包 / 没说 → `1:1`
3. 用户说「几张」「多来几张」就设置 `count`（最多 8）。
4. 用户说「再来一张一样的但是…」时，沿用上次的提示词修改；想保持构图就传上次返回的种子 `seed`。
5. 调用 `mcp_media_generate_image`，把返回结果里的每一行 `MEDIA:/路径` **原样**放进回复，再用一句话说明画了什么、用的比例。

## 示例
- `/img 一只戴墨镜的橘猫在海边冲浪，赛博朋克风` →
  prompt = "一只戴着黑色墨镜的橘猫站在冲浪板上，在霓虹灯照亮的夜晚海边冲浪，浪花飞溅，赛博朋克风格，霓虹粉紫色调，电影感光影，高细节，8k"，ratio = "16:9"
- `/img 小红书封面，标题"周末去哪玩"` →
  prompt = "小红书风格封面，明亮清新的配色，城市周末出游场景插画，画面中央大号手写体标题文字\"周末去哪玩\"，简洁排版"，ratio = "3:4"
