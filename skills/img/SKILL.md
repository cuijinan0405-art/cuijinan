# 一句话出图（千问 Qwen-Image 2.1）

## When to Use
- 用户输入 `/img <描述>`，或者说「画一张…」「出个图…」「来张…的图」「做个封面/海报」。
- 优先使用本地工具 `mcp_media_generate_image`，不要用其他在线出图工具。

## 怎么做
1. `prompt` 只写画面主体和内容（中文即可）：主体 + 场景 + 动作 + 关键细节。
   - 用户要求图中出现的文字，原样用引号写进提示词（千问 Image 擅长渲染中文文字）。
   - 用户只说了很短一句也不用追问，按合理默认补全后直接出图。
2. 风格交给 `style` 预设，不用自己堆风格词。常用预设：
   写实摄影、电影大片、人像写真、电商产品图、小红书封面、海报设计、日系动漫、国风水墨、
   清新水彩、儿童绘本、扁平插画、3D 卡通、黏土定格、赛博朋克、奇幻概念、古典油画、像素游戏、头像。
   拿不准有哪些时调 `mcp_media_list_styles`。用户没提风格就按内容挑一个最合适的。
3. 画幅 `ratio` 一般留空（用风格推荐的）；用户明确说了横版/竖版/方图时再填：
   竖版、手机壁纸、抖音 → `9:16`；横版、电脑壁纸、B 站封面 → `16:9`；方图、头像 → `1:1`。
4. 用户说「几张」「多来几张」就设置 `count`（最多 8）。
5. 「再来一张一样的但是…」：沿用上次的 prompt 和 style 修改；想保持构图就传上次返回的 `seed`。
6. 调用 `mcp_media_generate_image`，把返回结果里的每一行 `MEDIA:/路径` **原样**放进回复，再用一句话说明画了什么、用的风格。

## 示例
- `/img 一只戴墨镜的橘猫在海边冲浪` →
  prompt = "一只戴着黑色墨镜的橘猫站在冲浪板上，在夕阳下的海边冲浪，浪花飞溅"，style = "电影大片"
- `/img 小红书封面，标题"周末去哪玩"` →
  prompt = "城市周末出游场景，画面中央大号标题文字\"周末去哪玩\""，style = "小红书封面"
- `/img 国风 江南古镇 竖版` → prompt = "清晨的江南古镇，小桥流水，薄雾"，style = "国风水墨"，ratio = "9:16"
